# General
- Use built-in type hints without importing from typing module
- Prioritize readability and reproducibility
- Develop in Windows
- Use English for all documentation, comments, and code

# Frontend (Vue.js + TypeScript)
- **Build**: Vite | **State**: Pinia | **Router**: Vue Router
- Use composition API with `<script setup>` syntax
- Type props and use interfaces for complex data
- Create reusable components in `src/components`
- virtual scrolling for long lists
- Test with Vitest

# Backend (Python 3.12+)
- **Stack**: Pandas, FastAPI, pytest
- Follow PEP 8 with Black
- Prefer method chaining and vectorized operations
- Validate data at start, use logging not print()
- Write tests in /tests with fixtures
- Use Google-style docstrings with examples
